# Select All Option Removed

Changes made:

- Removed the `Select All` chip from the homepage hero chips.
- Removed the `Select All` chip from the Generate page options.
- Removed `Select All` URL aliases such as `?chip=select-all` and legacy `full-brand-kit` mapping.
- Removed the bundled 5-asset generation function from the Generate page.
- Kept normal single-asset generation intact: Website, Brand Images, Logo Design, Business Strategy, and Content Calendar.

Reason:

`Select All` could trigger 5 paid generations in one flow. Removing it keeps costs controlled and avoids accidental multi-asset spending.
